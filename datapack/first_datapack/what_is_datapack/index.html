What is a Datapack

A datapack is minecraft's solution to creating multiple commands that run in order. It also provides ways to create more versatile commands and modify data-driven features such as world generation, loot tables, and crafting recipes. At its simplest, a datapack lets you save commands into files instead of having to enter them manually every time you want to run them.

Functions​

The foundation of most datapacks is the function. A function is a file containing a list of commands that Minecraft executes in order when the function is called. For example, imagine you want to give a player some equipment, apply an effect, and teleport them to a location. You could execute each command individually, or put them together into a function.

give @s minecraft:iron_sword
effect give @s minecraft:speed 30 1
tp @s 0 100 0

When this function is executed, Minecraft runs the commands from top to bottom. This makes it possible to build larger systems out of smaller, reusable pieces of logic. Functions can also call other functions, allowing you to separate complicated systems into manageable parts. This is what datapackers call mcfunction files!
