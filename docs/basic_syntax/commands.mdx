# Commands
Minecraft commands have been a basic building block for interaction with the minecraft environment. Almost all minecraft datapacks use minecraft commands or rather known as 
*mcfunction* (Minecraft Function) files. There are many different ways to write commands and execute them in minecraft, either with the use of 
minecraft chat, command blocks, or datapacks.

## Chat Commands
With minecraft you can always execute any chat commands if you have **operator permissions**. To enable **operator permissions** either enable 
cheats when creating a world or have an operator use `/op <Player Name>` to give that person operator.  
When running a minecraft command in chat you start with the slash symbol `/`. This gives context to minecraft that you are running a command! 
Think of it like another language that the minecraft talks to, and by speaking this language you can ask it to do things.  
Running commands like the `/time` brings up options like `add` or `set` which are auto completed. Minecraft offers up auto completion 
when options are limited, if not then it will offer up type semantics if there is an expected output, but if all else failed then it will 
give an error if the command is not built up correctly like  
 `/give @s minecraft:acacia_log[minecraft:item_name=""]`.
