# Advancement
> Minecraft command for granting advancements to players.  

The `/advancement` command allows you to grant or revoke advancements to players.
The general command logic goes for the following `/advancement <grant|revoke> <selector> <operation> <advancement> [criterion]` 
**without the brackets \<\>**.
