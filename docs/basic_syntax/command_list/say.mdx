# Say
> Minecraft command for broadcasting messages.  

This command allows for natural display of text through interaction of the player.  
start the command with `/say`.  
Then your message!  

The full command will be like `/say <message>`.  
This is where `<message>` is like a greedy phrase where it takes all words and symbols after the command is invoked.  
This also means 
that you can't format the `<message>`.

## Selectors
The `/say` command does allow to parse `<selector>` arguments like `@s` or `@e` and return the output of the entity type or player name.

## Server side
This command is easy for server or datapacks themself to run quick test commands! Output will 
usually look something like this when ran in the server console.

```console
[Render thread/INFO]: [System] [CHAT] [Server] Hello World
```
## Command block output
When running `/say` through a command block it outputs as an entity with name `@` because of its empty selector.
```console
[Render thread/INFO]: [System] [CHAT] [@] Hello World
```

## Use cases
Useful for a quick debug when coding a datapack or adventure map.  
Great for when you want to broadcast messages to console.  
Useful for sending messages through server console.
