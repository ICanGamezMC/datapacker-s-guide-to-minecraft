# Components
The switch between nbt and components during `1.20.5` was a huge change with datapacks. This offered more readability and better stacking 
when it comes to writing custom data.

Components solved a major issue when it comes to clearly defined fields, making commands easier to read and maintain.
## Basic syntax

Items using components use the square brackets `[]` to define components. Components always follow snake case so instead of `[`**Tooltip Display**`={hide_tooltip:true}]` it's instead 
`[`**tooltip_display**`={hide_tooltip:true}]`.

Defining multiple components you need to use `,` like so `[rarity=uncommon,tooltip_display={hide_tooltip:true}]`. This is like a list of data that can be applied to an item
