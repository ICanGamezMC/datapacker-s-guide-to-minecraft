# What are command blocks?
command blocks are like chat commands stored in block data, useful for automatic running, and linking of commands. Command blocks are obtained either through the `/give @s minecraft:command_block` or operator tab configured in acessability settings.  
:::note[Usual use cases]
Usually minecraft commands are used in servers, adventure maps, demo scripts, or storage of commands.
:::
