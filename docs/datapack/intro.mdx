# Getting Started
> The start to achieve datapack nervana

Datapacks are minecrafts solution to running multiple minecraft [commands](../basic/basic_syntax/commands) globally almost all at once. generally contains either
json files or .mcfunction files, datapacks allow the anyone to modify how a vanilla game would run. This is where the part of what is considered *cheats* is now 
considered modding the game.
