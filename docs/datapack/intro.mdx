# Getting Started
> The start to achieve datapack nervana

Datapacks are minecrafts solution to running multiple minecraft [commands](../basic/basic_syntax/commands) globally almost all at once. generally contains either
json files or .mcfunction files, datapacks allow the anyone to modify how a vanilla game would run. This is where the part of what is considered *cheats* is now 
considered modding the game.

## What you will need
These are a few things needed and how to install based on your current setup of *nothing*.

### Vscode
To setup [Vscode](https://code.visualstudio.com/download?_exp_download=fb315fc982) you need to download and run the program. [Click here](https://www.geeksforgeeks.org/installation-guide/how-to-install-visual-studio-code-on-windows/) for a link to the guide!

[![large-image](https://media.geeksforgeeks.org/wp-content/uploads/20240206113523/1--Official-Page.png)](https://code.visualstudio.com/download?_exp_download=fb315fc982)

### Vscode Extentions
This extention pack will help install everything needed for creating datapacks. [Click here](https://marketplace.visualstudio.com/items?itemName=amandin.dpc-pack) for the download page or download via 
command `ext install amandin.dpc-pack`.  

[![small-image](https://amandin.gallerycdn.vsassets.io/extensions/amandin/dpc-pack/2.3.2/1769079168018/Microsoft.VisualStudio.Services.Icons.Default)](https://marketplace.visualstudio.com/items?itemName=amandin.dpc-pack)
