# Wiki Syntax

With writing or updating a document wiki syntax is important. You would use standard markdown format for most information, headers will appear 
on the sidebar of the wiki like how `Wiki Syntax` is being displayed currently.

There are two major parts to wiki syntax, one is `mdx` files or more called markdown files, and the other is `json` files or rather called category files. 

## Markdown Files
Getting started editing or creating a new markdown file always follows these things, a header, content, and external resources where there more information could be found.
Some files have a page theme like this one and there is a grouping to page themes.

Pages with a header will always have:
```mdx
---
sidebar_position: 2
sidebar_class_name: icon-home
---
```
Sometimes there will need to be context if information is tied to minecraft or other minecraft relating aspects like `datapacks` or `beet`.
To use this you can create a modified header which would include the info card telling which version the page was last checked.
```mdx
---
sidebar_position: 2
sidebar_class_name: icon-home
minecraft_version: "26.2"
---
```
After that there is usually just standard mark down format with using symbols like `#` for headers and `*` for lists.

At the bottom of the general pages there should be resources section where information and assets are found.
It looks roughly like this:
```mdx
### Reference

Information:  

Assets:  
```

For page themes with different colored pages it should go as followed
* nothing for introducion and basics tab
* `page-blue` for wiki related information like this section!
* `page-orange` for datapack tab

To use it inside a markdown file copy and change the `colorClass` to said theme
```js
import ThemeWrapper from '@site/src/components/ThemeWrapper';

<ThemeWrapper colorClass="page-blue">
</ThemeWrapper>
```
This color class has to be at the very bottom of the page.

Using notes inside the markdown file should be sparce, in the sence that you should not see the same type of note on the same page twice without scrolling.
With the code you can create a markdown note like this:
```mdx
:::note[This is a title for the note]
This is a note
:::

```
What it looks like:
:::note[This is a title for the note]
This is a note
:::


import ThemeWrapper from '@site/src/components/ThemeWrapper';

<ThemeWrapper colorClass="page-blue">
</ThemeWrapper>
