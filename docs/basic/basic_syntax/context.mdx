# Context
> Situations where the thing executing matters

When running commands there is certain assuption when things like a `give @s` command is being ran. If you are just typing it out 
and you give yourself diamonds because *you* ran it you get the item from the context of current entity running it.  
Think of context situations and **questions you can ask yourself** if a command isn't running how it should.
- Where is the command running?
- Who is running the command?
- What conditions should the command check for?
- When should a command run / how long should it run?
