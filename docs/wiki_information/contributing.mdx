# Contributing
- **Content should be cumulative and ordered based on where and how it should be learned.**  

What this means is that information is explained thoroughly and readable from people who are new to everything command related to people who know how to make bolt libraries. 
Ordered just means from top to bottom where it can be followed from one peace of information on the top to the next one below it.

- **Content info should be a mix of skimable and complete.**  

Skimable means highlighting and it is everything; include images when possible and markdown. Make sure information tries to be complete, so indepth knowledge 
is useful and nothing is missing.

- **Content should include examples and tutorials for introducing new code.**  



- **Content being explained/described should be one-on-one.**  

- **Content should contain references to other sources for more information.**
