# Datapacker's guide to Minecraft!
Welcome to *DGTM* or rather called Datapacker's guide to minecraft! This wiki has guides to start people out from learning **basic minecraft syntax** to learning how to code different languages to **compile into complex minecraft code**! 
There will be tons of references to other sources.
## Getting Started
To get started the tutorials will be running in minecraft version [26.1](https://minecraft.wiki/w/Java_Edition_26.1).  
Later on when coding there will be use of [vscode](https://code.visualstudio.com/download) for its language highlighting syntax.  
If you are just starting to learn minecraft syntax [click here](./intro#for-beginners) for more information.

This wiki is still heavily work in progress, everything on every page is being updated and added on to.  
There is currently only command syntax being worked on, after that command creations, then datapacks.
:::
